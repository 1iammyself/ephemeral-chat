# Ephchat Landing Page

A modern, responsive landing page for Ephchat - the privacy-first ephemeral messaging app.

## Features

- 🎨 Premium gradient design with smooth animations
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Lightweight (no framework dependencies)
- 🎯 SEO optimized
- 🚀 Ready for Vercel deployment

## Local Development

Simply open `index.html` in your browser. No build step required.

## Deploy to Vercel

1. Install Vercel CLI:
```bash
npm i -g vercel
```

2. Deploy:
```bash
cd landing-page
vercel
```

3. Set custom domain:
   - Go to your Vercel dashboard
   - Select the project
   - Go to Settings → Domains
   - Add `ephchat.kyere.me`

## Customization

- **Colors**: Edit CSS variables in `styles.css` `:root` section
- **Content**: Edit text directly in `index.html`
- **Download links**: Update URLs in `index.html`
