Frequently Asked Questions

How does screenshot protection work?

The Android and Desktop apps use platform-specific APIs to block screenshot capture and screen recording while the app is active.

Where are messages stored?

Messages are only stored in memory and are never written to disk. They disappear when all participants leave the room.

Is it end-to-end encrypted?

All communication uses secure WebSocket connections (WSS) and WebRTC for calls. We're working on adding E2EE for an extra layer of security.
